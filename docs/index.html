MC AI Companion

A Minecraft bot that plays alongside you. An AI decides what to do and says what it thinks; fast code does the walking, mining, fighting and building.

Get it on GitHub Read the changelog

Early version (0.8.1). The core bot has run on a real server; the newer features pass 115 automated tests in simulated worlds but are still being tried out in real games.

It lives in your world

Nobody owns it. It has a personality you write, its own needs and goals, and a memory that survives restarts. Ask it for help and it decides like a person would: gladly, grudgingly, for a price, or not at all.

  • Needs. Night is coming and there's no shelter. Food is running low. A stone pickaxe would be better than wood. It notices and acts.
  • Goals and memory. It sets its own long-term goals, remembers places and what it thinks of each player, and keeps a short journal.
  • Senses. It reacts to sunsets, storms, creepers, diamonds, and friends arriving or handing it things.
  • Never just standing there. It plans its next step while still working, gives up on stuck tasks, and falls back to sensible chores if the AI goes quiet.
  • Operators stay in charge. Server OPs can stop, pause, redirect or completely wipe it with ! commands it can't refuse.

It gets better with practice

Every bot starts as a beginner: dirt huts with a few gaps, scraping ore off cliff faces, panicking at zombies. It earns experience from what it actually gets done, and climbs tiers. It moves from Cabin builder to Homesteader to Architect with two-storey houses, and from Tunneler to Deep miner. Give each bot its own talents and they grow into different roles.

It keeps a farm

It starts with a little wheat patch beside a pond. As it improves it brings its own bucket of water, plants carrots, potatoes and beetroot, fences the field and breeds animals. It comes back to harvest and replant once the crops have had time to grow.

One day, the Nether

Only seasoned fighters and miners get this far. It builds and lights a portal near home, then makes careful trips for quartz, glowstone, blaze rods or piglin trades, and turns back when it gets hurt.

It connects the neighborhood

About once a week it may offer a player a powered minecart line from its base to theirs, if it has the iron, gold and redstone or can easily mine them. Say yes and it surveys the route, tunnels through hills, bridges water, powers the track and builds a station at each end.

It builds a proper home

Ask for a base and it finds the flattest dry spot nearby, clears the trees, levels the ground and builds a log-framed house with a floor, windows, a door, a roof, torches and furniture. Or it digs one: a covered stairwell with double doors down to a lit room, with every cave, water pocket and lava leak sealed off.

Tidy
Chests, tables, furnaces and beds go against walls, out of walkways and away from doors. A second chest joins the first into a double chest.
Careful
It never digs inside a base or breaks anything a player placed, and it picks up the crafting tables it leaves out in the wild.
Patient
Big builds are projects. When it runs out of blocks it says exactly what it needs, goes to get them and carries on where it stopped.
Varied
Each base is picked at random from the designs it knows: a cottage, longhouse, stone watchtower or L-shaped farmhouse, or underground a cellar or pillared hall.
End game
Master builders raise a two-storey manor or dig a fortress into a hillside, with a vault of double chests, a full forge, an enchanting library, beds for everyone and a brewing room.
Growing
As it gets better it adds to the home it has: a storage room, a bunker under the floor, a second storey, an enchanting room ringed with bookshelves.

It digs a real mine

No more holes in your floor. It picks an entrance away from every base, digs one clean covered staircase down to the right depth for what it wants, then branch-mines there and clears out every vein it uncovers. Next trip, it goes back to the same mine.

How it works

The AI is slow and thoughtful, the game is fast. So they're split: the AI is only asked when something happens, and plain code keeps the body moving in between.

Brain
Any language model. It reads what the bot sees, needs and remembers, then replies with something to say and a short plan of actions.
Body
Pathfinding, mining, combat, crafting, building and railway laying, running every game tick. Reflexes eat, fight back and flee without waiting for the AI.

Works with Ollama (free, runs on your PC), OpenAI, Anthropic Claude, Google Gemini, and anything that speaks the OpenAI format, like LM Studio, OpenRouter or Groq. Switching is one line in the config.

Set it up

  1. Install Node.js 20 or newer, and either Ollama or an API key for a cloud model.
  2. Download the project and install its packages: 
    git clone https://github.com/Advancemintz/mc-ai-companion
cd mc-ai-companion
npm install
  3. Edit config.json: pick your AI provider and write the bot's personality.
  4. Open a Minecraft Java 1.21.x world to LAN (or start a server) and put the port in the config.
  5. Start the bot with npm start (or double-click start.bat on Windows), then say hi in chat.

The README covers connecting, every setting, every command and troubleshooting.
